# つみノート Product Specification

## 1. 概要

「つみノート」は、

**勉強する → 記録する → 復習する**

という学習サイクルを1つのアプリで完結させるiPhone / iPad向け学習管理アプリ。

アカウント登録を必須にせず、Local Firstで全主要機能を利用できることを基本方針とする。

アカウントを作成すると、既存のローカルデータを引き継ぎ、iPhone / iPad間で同期できる。

---

# 2. 対象プラットフォーム

v1：

- iPhone
- iPad

Androidはv1の公開対象外。

表示・操作：

初期設定：

```text

```

集中と休憩を設定ラウンド数繰り返す。

### タイマー状態

以下の状態を持つ。

- 集中中
- 休憩中
- 一時停止
- ラウンド完了

状態画面は未デザイン。

### タイマー設定

未デザイン。

設定：

- 集中時間
- 休憩時間
- ラウンド数

### Background対応

単純なsetIntervalのカウントを正としない。

開始時刻・終了予定時刻から、

```text
remaining = endAt - currentTime
```

の考え方で残り時間を算出する。

Background / Foreground復帰 / 画面ロックによる大きな時間ずれを防止する。

### 集中終了

集中セッション完了時：

- ローカル通知
- 振動
- 学習セッション保存

選択されているフォルダーと学習セッションを関連付ける。

# 11. 復習

## 10 復習

デザイン済み。

復習期限が来ている問題を期限の近い順に出題する。

フロー：

```text
問題表示
↓
ユーザーが考える
↓
答えを見る
↓
評価
↓
次の問題
```

答えを表示した時点で制限時間の計測を停止する。

評価：

```text
もう一度
難しい
普通
簡単
```

FSRS：

```text
もう一度 → Again
難しい   → Hard
普通     → Good
簡単     → Easy
```

# 13. FSRS

復習スケジューリングにはFSRSを使用する。

`ts-fsrs` を利用する。

独自SM-2アルゴリズムは実装しない。

以下を分離する。

```text
Review History
        ↓
      FSRS
        ↓
Current FSRS State
        ↓
    Next Due
```

過去の復習履歴をFSRS現在状態で上書きしない。
