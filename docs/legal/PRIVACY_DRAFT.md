# プライバシーポリシー

制定日:2026年9月25日

hosokawa-lab(以下「運営者」)は、学習アプリ「つみノート」および関連する Web サイト(以下あわせて「本サービス」)における利用者の個人情報を、個人情報の保護に関する法律その他の法令に従い、以下のとおり取り扱います。

## 1. 取得する情報

- **アカウント情報**:アカウントを作成した場合の、メールアドレス、表示名、ログイン方法(メールとパスワード / Apple / Google)。パスワードは、元の文字列ではなく変換(ハッシュ化)した値を保存します。
- **Apple・Google でサインインした場合の情報**:各社が発行する、利用者を識別するための ID、メールアドレス、名前、および各社が発行した認証用の情報(ID トークン)。
- **学習データ**:アカウントを作成し同期機能を利用した場合の、フォルダー、ノート、問題、復習の予定・履歴、回答の履歴、学習記録、目標、設定。
- **ノートの画像**:アカウントを作成し、ノートに挿入して同期した画像ファイル。
- **ログイン状態の情報**:ログイン状態の管理のために、IP アドレスと端末・OS の情報(User-Agent)を記録します。
- **お問い合わせ情報**:お問い合わせフォームに入力されたお名前、メールアドレス、お問い合わせ内容
- **アクセス情報**:Web サイトへのアクセス時に記録される IP アドレス、ブラウザの種類、アクセス日時など
- **操作の回数の記録**:不正利用の防止のため、ログイン・登録などの操作の回数と時刻を記録します。

**ゲスト(アカウントなし)での利用**:アカウントを作成しない場合、学習データ・画像は利用者の端末内にのみ保存され、運営者が取得することはありません。アカウントを作成した後も、アプリは端末内のデータを主に利用し、同期のために必要な範囲でサーバーと通信します。ゲストとして作成したデータをアカウントへ引き継ぐ場合は、その時点でサーバーへ送信されます。

**取得しないもの**:位置情報、連絡先、広告識別子は取得しません。また、アクセス解析・広告・クラッシュレポートを目的とした外部の仕組みは、アプリに組み込んでいません。

**端末の機能について**:ノートに画像を挿入するときは、端末の写真選択画面から利用者が選んだ画像のみをアプリが受け取ります。学習のリマインダーとタイマーの通知は、端末内で予約される通知であり、通知のために情報をサーバーへ送信しません。

## 2. 利用目的

- 本サービスの提供、端末間のデータ同期・バックアップ
- アカウントの認証、メールアドレスの確認、パスワード再設定のご案内メールの送信
- お問い合わせへの回答、重要なお知らせの連絡
- 不正利用の防止、障害対応、セキュリティの確保
- 本サービスの改善

## 3. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。

## 4. 外部サービスの利用

運営者は、本サービスの提供にあたり、次の外部サービスに個人情報の取り扱いを委託しています。

- **Cloudflare, Inc.(米国)**:Web サイトのホスティング、アクセス情報の処理、アプリの同期・認証 API の実行(Cloudflare Workers)、アカウント情報と学習データの保存(Cloudflare D1)、ノート画像の保存(Cloudflare R2)
- **Resend(Plus Five Five, Inc.、米国)**:お問い合わせ内容のメール送信、およびメールアドレスの確認・パスワード再設定・登録済みのメールアドレスでの再登録のお知らせの各メールの送信(宛先のメールアドレスと、リンクを含むメール本文を渡します)

利用者が選択した場合、次の事業者のサインイン機能を利用します。これらの事業者は、各社のプライバシーポリシーに基づいて情報を取り扱います。

- **Apple Inc.**(Sign in with Apple)
- **Google LLC**(Google でサインイン)

これらの事業者は外国に所在するため、個人情報は日本国外で取り扱われることがあります。

## 5. Cookie について

本 Web サイトでは、現在アクセス解析や広告を目的とした Cookie は使用していません。

## 6. 安全管理

運営者は、個人情報の漏えい・滅失・毀損を防ぐため、通信の暗号化やアクセス権限の管理など、必要かつ適切な措置を講じます。

## 7. 保存期間と削除

- **ゲスト**:データは利用者の端末内にのみあり、アプリを削除すると端末から消えます。運営者は削除も復元もできません。
- **アカウントを作成した場合のデータ**:アカウント情報、同期された学習データ、ノート画像は、アカウントを削除するまで運営者のサーバーに保存します。ログアウトしても、サーバー上のデータは削除されません。
- **アカウントの削除**:アプリのマイページ → アカウントから削除を実行できます。削除は元に戻せません。
  - **サーバー上のデータ**:削除の手続きが完了すると、アカウント情報、ログイン状態の情報、同期された学習データ、ノート画像が、運営者のサーバー(Cloudflare D1・R2)から削除されます。通信の状況やサーバーの障害などにより手続きが完了しない場合は、アプリに表示される案内に従って再度実行してください。画像の削除は、削除後も一定期間、運営者が繰り返し確認して行います。
  - **削除を実行した端末**:サーバーでの削除の完了後、その端末に保存されているそのアカウントのデータと画像も削除されます。
  - **ほかの端末**:削除を実行していない端末に保存されているデータと画像は、運営者から遠隔で削除することはできず、その端末に残ります。不要な場合は、各端末でアプリを削除するなどして消去してください。ゲストとして保存したデータは削除されません。
  - **ログ・バックアップ**:Cloudflare などの外部サービスが保持するログやバックアップに、削除後も一定期間データが残る場合があります。
- **同期データの削除の記録**:ノートや問題などを削除すると、ほかの端末へ削除を伝えるため、サーバー上に削除の記録が残ります。この記録には、削除した項目の内容が含まれる場合があります。記録は、アカウントを削除するまで保持します。
- **ログイン状態**:有効期間は最長30日です。
- **メール確認・パスワード再設定のリンク**:有効期間は1時間です。
- **お問い合わせ内容・アクセス情報・操作の回数の記録**:利用目的の達成に必要な期間保存します。

## 8. 開示・訂正・削除の請求

利用者は、運営者が保有する自己の個人情報について、開示・訂正・利用停止・削除を請求できます。アカウントと同期データは、アプリのマイページ → アカウントからいつでも削除を実行できます。また、アプリの「プライバシーとデータ」から、端末内のデータを JSON ファイルで書き出せます。書き出しには、フォルダー、ノート、問題、復習の予定・履歴、回答の履歴、学習記録、目標、設定が含まれます(削除済みの項目の記録を含む場合があります)。ノートの画像ファイル、アカウント情報、ログイン状態の情報は含まれません。その他の請求は、お問い合わせフォームからご連絡ください。ご本人であることを確認したうえで、遅滞なく対応します。

## 9. プライバシーポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。変更後の本ポリシーは、本ページに掲載した時点から効力を生じます。
