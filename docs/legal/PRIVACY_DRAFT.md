# プライバシーポリシー

制定日:2026年9月25日
改定日:【未定】

hosokawa-lab(以下「運営者」)は、学習アプリ「つみノート」および関連する Web サイト(以下あわせて「本サービス」)における利用者の個人情報を、個人情報の保護に関する法律その他の法令に従い、以下のとおり取り扱います。

## 1. 取得する情報【変更】

- **アカウント情報**:アカウントを作成した場合の、メールアドレス・表示名・ログイン方法(メールとパスワード / Apple / Google)。パスワードは、元の文字列ではなく変換(ハッシュ化)した値を保存します。【変更】
- **Apple・Google でサインインした場合の情報**【追加】:各社から提供される、利用者を識別するための ID、メールアドレスおよび名前。❓要事実確認(認証ライブラリが保存するトークン類の扱い。LEGAL_REVIEW.md 参照)
- **学習データ**:アカウントを作成し同期機能を利用した場合の、学習記録、ノート、フォルダー、問題、復習の予定・履歴、目標、設定。【変更:項目を実装に合わせて列挙】
- **ノートの画像**【追加】:ノートに挿入し、同期した画像ファイル。
- **ログイン状態の情報**【追加】:ログインの有効期間(最長30日)の管理のために、IP アドレスと端末・OS の情報(User-Agent)を記録します。
- **お問い合わせ情報**:お問い合わせフォームに入力されたお名前、メールアドレス、お問い合わせ内容
- **アクセス情報**:Web サイトへのアクセス時に記録される IP アドレス、ブラウザの種類、アクセス日時など
- **操作の回数の記録**【追加】:不正利用の防止のため、ログイン・登録などの操作の回数と時刻を記録します。

**ゲスト(アカウントなし)での利用**【変更】:アカウントを作成しない場合、学習データ・画像は利用者の端末内(SQLite データベースとアプリの保存領域)にのみ保存され、運営者が取得することはありません。アカウントを作成した後も、アプリは端末内のデータを主に利用し、同期のために必要な範囲でサーバーと通信します。ゲストとして作成したデータをアカウントへ引き継ぐ場合は、その時点でサーバーへ送信されます。

**取得しないもの**【追加】:位置情報・連絡先・広告識別子は取得せず、アクセス解析・広告の SDK は使用していません。❓要事実確認(リリースビルドの依存関係で最終確認)

**端末の機能について**【追加】:写真ライブラリへのアクセスは、ノートに挿入する画像を選ぶ目的に限ります。学習のリマインダーとタイマーの通知は、端末内で予約されるローカル通知であり、通知のために情報をサーバーへ送信しません。

## 7. 保存期間と削除【追加:新設章。以降の章番号は1つずつ繰り下げ】

- **ゲスト**:データは利用者の端末内にのみあり、アプリを削除すると端末から消えます。運営者は削除も復元もできません。
- **アカウントを作成した場合の学習データ・画像・アカウント情報**:アカウントを削除するまで保存します。ログアウトしても、サーバー上のデータは削除されません。
- **アカウントの削除**:アプリのマイページ → アカウントから実行できます。実行すると、アカウント情報、同期された学習データ、ノート画像を、運営者のサーバー(D1・R2)から削除します。削除は元に戻せません。削除の処理が途中で止まった場合は、再実行で完了します。また、削除後に画像が残っていないかを定期的に確認し、残っていれば削除します。この端末に保存されているそのアカウントのデータと画像も削除されます。
- **同期データの「削除」の扱い**:ノートや問題などを削除すると、他の端末へ削除を伝えるため、サーバー上に削除済みの印(内容を含む場合があります)が残ります。これはアカウントを削除するまで保持されます。❓要事実確認(現状、削除済みデータを期間経過後に物理削除する処理は確認できませんでした)
- **ログイン状態**:最長30日です。
- **メール確認・パスワード再設定のリンク**:有効期間は1時間です。
- **お問い合わせ内容・アクセス情報**:❓要事実確認(保存期間の運用が確認できません。例:お問い合わせ対応の完了後◯か月)
- **バックアップ・ログ**:❓要事実確認(Cloudflare 側のバックアップ・ログに削除後も一定期間残る場合の記載。D1 の復元機能、Workers のログ設定を確認してください)

> ⚠️要法務確認:保存期間を具体的な期間として記載する必要性(保存期間の公表は必須ではないが、利用目的達成後の遅滞なき消去の努力義務がある)。

利用者は、運営者が保有する自己の個人情報について、開示・訂正・利用停止・削除を請求できます。アカウントと同期データは、アプリのマイページ → アカウントからいつでも削除できます。【追加】アプリの「プライバシーとデータ」から、データを JSON ファイルで書き出せます(ノートの画像ファイルは含まれません)。その他の請求は、お問い合わせフォームからご連絡ください。ご本人であることを確認したうえで、遅滞なく対応します。
