# 利用規約

制定日:2026年9月25日
改定日:【未定】

この利用規約(以下「本規約」)は、hosokawa-lab(以下「運営者」)が提供する学習アプリ「つみノート」および関連する Web サイト(以下あわせて「本サービス」)の利用条件を定めるものです。本サービスを利用する方(以下「利用者」)は、本規約に同意したうえで本サービスを利用するものとします。

## 第1条(適用)

*(変更なし)* 本規約は、利用者と運営者との間の本サービスの利用に関わる一切の関係に適用されます。App Store を通じて本サービスを入手した場合は、Apple が定める利用条件もあわせて適用されます。

## 第2条(アカウント)【変更】

1. 【追加】本サービスの主要な機能は、アカウントを作成しなくても(ゲストとして)利用できます。ゲストとして作成したデータは、利用者の端末内にのみ保存されます。
2. 本サービスの一部の機能(端末間の同期・バックアップなど)は、アカウントを作成した場合に利用できます。【変更:「バックアップ」を追加】
3. 【追加】アカウントは、メールアドレスとパスワード、Apple でサインイン、または Google でサインインのいずれかの方法で作成できます。メールアドレスで登録する場合は、メールアドレスの確認が必要です。Apple・Google のアカウントの管理や利用条件は、各社の定めによります。
4. 利用者は、自己の責任においてアカウントを管理するものとし、第三者に利用させてはなりません。
5. 利用者は、アプリのマイページからいつでもアカウントを削除できます。削除すると、運営者のサーバーに保存されたデータ(同期されたデータおよびノート画像を含みます)は削除され、元に戻せません。【変更】他の端末は同期できなくなります。また、削除したアカウントのデータは、削除を行った端末からも削除されます。ゲストとして保存したデータは削除されません。【追加】
6. 【追加】ログアウトしても、サーバーに保存されたデータは削除されません。

## 第3条(利用者のデータ)【変更】

1. 利用者が本サービスに入力したノート・問題・学習記録などのデータ(以下「利用者データ」)の権利は、利用者に帰属します。
2. 運営者は、本サービスの提供・維持・改善に必要な範囲でのみ利用者データを取り扱います。*(既存文面を維持)*
3. 【追加】アカウントを作成した場合、利用者データ(ノート、フォルダー、問題、復習の予定・履歴、学習記録、目標、設定およびノートに挿入した画像)は、同期・バックアップのため運営者が利用するクラウドサービスに保存されます。取り扱いの詳細は[プライバシーポリシー](https://tsumi-note.hosokawa-lab.dev/privacy)に定めます。
4. 【追加】利用者は、アプリの「プライバシーとデータ」からデータを JSON ファイルとして書き出すことができます。なお、ノートの画像ファイルは書き出しに含まれません。

## 第4条(禁止事項)

*(変更なし)* 利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

- 法令または公序良俗に違反する行為
- 第三者の著作権その他の権利を侵害する内容を登録する行為
- 本サービスのサーバーやネットワークに過度な負荷をかける行為、または運営を妨害する行為
- 不正アクセス、リバースエンジニアリングその他本サービスの不正な利用
- その他、運営者が不適切と判断する行為

## 第5条(本サービスの変更・停止)

*(変更なし)* 運営者は、保守・障害対応その他やむを得ない事情があるときは、利用者に事前に通知することなく、本サービスの全部または一部の提供を変更・中断・終了できるものとします。

> ⚠️要法務確認:同期・バックアップ機能を終了する場合の事前通知や、データを取り出す猶予期間を設けるかどうか(現行は「事前に通知することなく」)。

## 第6条(知的財産権)

*(変更なし)* 本サービスに関するプログラム・デザイン・文章などの知的財産権は、利用者データを除き、運営者または正当な権利者に帰属します。

## 第7条(免責事項)【変更】

1. 運営者は、本サービスが利用者の特定の目的に適合すること、学習の成果が得られること、および不具合やデータの消失が生じないことを保証しません。大切なデータは利用者自身でも控えを保管してください。*(既存文面を維持)*
2. 【追加】端末の故障・紛失・アプリの削除などにより、アカウントを作成していない(ゲストの)データが失われた場合、運営者はデータを復元できません。アプリの「データを書き出す」機能などでバックアップを取ることを推奨します。
3. 【追加】複数の端末で同じデータを同時に編集した場合、同期の際に内容が競合することがあります。この場合、本サービスはいずれの内容も失わないよう複製を残すことがありますが、内容の統合は保証しません。
4. 運営者は、本サービスに関して利用者に生じた損害について、運営者の故意または重大な過失による場合を除き、責任を負いません。*(既存文面を維持。旧第2項)*

> ⚠️要法務確認:第4項の免責が消費者契約法(第8条など)上有効に働く範囲。

## 第8条(規約の変更)

*(変更なし)* 運営者は、必要と判断した場合には本規約を変更できます。変更後の本規約は、本ページに掲載した時点から効力を生じるものとし、重要な変更がある場合は本サービス上でお知らせします。

> ⚠️要法務確認:「重要な変更」の通知方法(アプリ内での通知の実装は未確認)。民法548条の4(定型約款の変更)の要件に照らした文言。

## 第9条(個人情報の取り扱い)

*(変更なし)* 運営者は、利用者の個人情報を[プライバシーポリシー](https://tsumi-note.hosokawa-lab.dev/privacy)に従って適切に取り扱います。

## 第10条(準拠法・管轄裁判所)

*(変更なし)* 本規約の解釈には日本法を準拠法とし、本サービスに関して紛争が生じた場合には、運営者の住所地を管轄する地方裁判所を第一審の専属的合意管轄裁判所とします。

> ⚠️要法務確認:個人運営で住所を公開していない場合の管轄の書き方。利用者が消費者の場合の専属的合意管轄の有効性。
